# Трекер полезных привычек

Курсовой проект — backend SPA-приложения для управления
полезными привычками и отправки напоминаний в Telegram.

## Статус

Проект находится на этапе начальной настройки.

## Планируемые возможности

- Регистрация и вход по email.
- JWT-авторизация.
- Создание, просмотр, редактирование и удаление своих привычек.
- Просмотр публичных привычек.
- Валидация привычек.
- Пагинация через LimitOffsetPagination.
- Напоминания в Telegram через Celery.
- Документация API через Swagger и ReDoc.

## Планируемый стек

Python, Django, Django REST Framework, PostgreSQL,
Celery, Redis, Telegram Bot API, Poetry.

## Установка зависимостей

Требуются Python и Poetry. Ограничения версий указаны
в pyproject.toml.

```powershell
poetry install
```

Инструкция по настройке и запуску будет дополнена
по мере разработки.

## Работа с Git

- main — основная ветка.
- develop — ветка для приёма выполненной работы.
- feature/habit-tracker — разработка курсового проекта.

Курсовая сдаётся через Pull Request
из feature/habit-tracker в develop.
